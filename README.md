# Using Feature Flags in a Next.js Application Sample App

**[Read the blog post here](https://configcat.com/blog/2022/04/22/how-to-use-feature-flags-in-nextjs/)**

This sample application demonstrates how to use feature flags in a Next.js application. It complements the blog post linked above and can be used as a code example when using [ConfigCat feature flags](https://configcat.com/featureflags) in your Next.js application.

## Build & Run

### Prerequisites

- The latest stable versions of [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/) installed.
- A code editor like [VS Code](https://code.visualstudio.com/) installed.
- [Git](https://git-scm.com/downloads) installed to clone the sample project from GitHub.

### Running the sample app

1. Clone this code repository:

```sh
git clone git@github.com:configcat-labs/feature-flags-in-nextjs-sample.git
```

2. Navigate to the cloned project folder and install the npm package dependencies:

```sh
npm install
```

3. Create a `.env.local` file in the root of the repo and add your ConfigCat SDK Key to it:

```env
CONFIGCAT_SDK_KEY=YOUR-CONFIGCAT-SDK-KEY
```

4. Start the development server using the command below, then click the link printed in your terminal to launch the sample app in your browser.


```sh
npm run dev
```
